Build common application features with the JavaScript SDK.
Each recipe includes setup, code you can connect to your application's interface, and steps to check the result.

Start with [user signup and login](./user-signup-and-login.md); the other recipes reuse its authenticated client.
If you need a project first, follow the [quickstart](/get-started/quickstart).

For platform concepts and API references, explore the [Docs](/).
