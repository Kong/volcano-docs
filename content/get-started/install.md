## CLI

Install globally with your package manager of choice:

```bash
npm install -g @volcano.dev/cli
# or: pnpm add -g @volcano.dev/cli
# or: bun add -g @volcano.dev/cli
# or: brew install Kong/volcano/volcano

volcano --help
```

See the [CLI docs](/cli) for the full command reference and other install
methods.

## JavaScript SDK

Add the SDK to your project:

```bash
npm install @volcano.dev/sdk
# or: pnpm add @volcano.dev/sdk
```

See the [SDK docs](/sdk/js) for configuration and your first request.
